# Plan 999.12-04: HTTP surfaces — COMPLETE

## Outcome

All HTTP surfaces for the personal-context MCP shipped. External agents can now hit `https://<host>/api/mcp` with a bearer token and discover/call `get_current_context` + `get_snapshot_history`. The nightly Vercel cron at `0 5 * * *` (00:00 ET) builds and persists per-user snapshots. The authenticated user can force a snapshot rebuild via `POST /api/context/rebuild`.

**Cron + manual surfaces (`apps/web/app/api/`)**
- `cron/snapshot-context/route.ts` — Node runtime, `Authorization: Bearer ${CRON_SECRET}` gate (missing → 500 fail-loud, wrong → 401). Iterates `auth.users`, calls `buildSnapshot` + `persistSnapshot` per user; per-user failures don't abort the loop. Returns `{ ok, snapshots_written, failures }`.
- `cron/snapshot-context/__tests__/route.test.ts` — 7 specs covering all auth + persistence paths.
- `context/rebuild/route.ts` — POST gated by `getClaims()` (CLAUDE.md Critical Pattern 1 — `getSession()` is forbidden). Rebuilds only the caller's own snapshot (no cross-user vector).
