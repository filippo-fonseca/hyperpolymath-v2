<objective>
LAT-01 — switch the TTS pipeline transport from MP3 to raw 16-bit signed
little-endian PCM at 24 kHz mono, removing the `decodeAudioData` step that
costs ~15-30ms per chunk AND eliminating the upstream-side MP3 frame-
alignment requirement that forced the full-body buffer in `use-tts-player`
(LAT-03 follow-on in Plan 10-04 will exploit this).

Purpose: voice character is unchanged (same ElevenLabs voice, same accent
— synthesis is identical; only transport encoding differs), but the
client decode step drops out entirely. PCM is frame-aligned trivially
(2 bytes per sample) so chunks of arbitrary size are gapless.

Output:
- Server: `output_format=pcm_24000` upstream + response Content-Type
  switched to `application/octet-stream`. 502 sentinel for upstream
  failure preserved (Phase 7 Pitfall 7).
- Client: `AudioQueue.enqueue(chunk)` rewritten to build the AudioBuffer
  directly from `Int16Array → Float32Array` at `sampleRate: 24000`. ALL
  Phase 7 / Phase 9 invariants preserved (analyser tap, `firstPlayCaptured`
  one-shot, `scheduledEnd` gapless chaining, `onAllEnded`, `stopAll`).
- Test: a byte-order sanity test verifying that a known Int16 sine-wave
  input round-trips to the expected Float32 output within tolerance.

Locked decisions consumed (from 10-CONTEXT.md):
- D-03: Per-network-chunk AudioBuffer. Each ReadableStream chunk becomes
  one Int16Array → Float32Array → AudioBuffer scheduled at
  `Math.max(audioCtx.currentTime, scheduledEnd)`. Per-sentence buffer
  rejected (would violate LAT-03's "as they arrive" semantics).
- D-03: 16-bit signed little-endian @ 24kHz mono. Odd-byte runt retained
  across chunks; single-byte spill is the only valid leftover.
- Discretion: Int16 → Float32 conversion uses `int16 / 32768.0`
  (equivalent to `int16 / 0x8000`). Both produce identical Float32 output;
  use the literal `32768.0` form for readability.
- Out of scope: per-sentence dispatch wiring, use-tts-player.ts rewrite,
  TurnPlaybackController (all in Plan 10-04).
</objective>

```typescript
// Module-level (so leftoverByte survives across enqueue calls within same AudioQueue):
private leftoverByte: Uint8Array | null = null;

async enqueue(chunk: ArrayBuffer): Promise<AudioBufferSourceNode> {
  // 1. Merge leftover from prior chunk (if any) + this chunk's bytes.
  let bytes = new Uint8Array(chunk);
  if (this.leftoverByte) {
    const merged = new Uint8Array(this.leftoverByte.length + bytes.length);
    merged.set(this.leftoverByte, 0);
    merged.set(bytes, this.leftoverByte.length);
    bytes = merged;
    this.leftoverByte = null;
  }
  // 2. If odd length, retain trailing byte for next chunk.
  if (bytes.length % 2 === 1) {
    this.leftoverByte = bytes.slice(bytes.length - 1);
    bytes = bytes.slice(0, bytes.length - 1);
  }
  // 3. Int16 (LE) → Float32 in [-1.0, 1.0).
  const sampleCount = bytes.length / 2;
  const int16 = new Int16Array(
    bytes.buffer, bytes.byteOffset, sampleCount,
  );
  const float32 = new Float32Array(sampleCount);
  for (let i = 0; i < sampleCount; i++) {
    float32[i] = int16[i] / 32768.0;
  }
  // 4. Build the AudioBuffer at the PCM sample rate.
  const buffer = this.ctx.createBuffer(
    1,             // numberOfChannels = mono
    sampleCount,   // length in samples (NOT bytes)
    24000,         // sampleRate (matches output_format=pcm_24000)
  );
  buffer.copyToChannel(float32, 0);
  // 5. Source node + analyser tap + scheduling identical to current code path.
  const node = this.ctx.createBufferSource();
  node.buffer = buffer;
  if (this.analyserNode) {
    node.connect(this.analyserNode);
    this.analyserNode.connect(this.ctx.destination);
  } else {
    node.connect(this.ctx.destination);
  }
  const startAt = Math.max(this.ctx.currentTime, this.scheduledEnd);
  node.start(startAt);
  // Phase 9 / TEL-01 — first audio-out moment per AudioQueue lifecycle.
  if (!this.firstPlayCaptured) {
    this.firstPlayCaptured = true;
    collectStage("audio_first_play_at", new Date());
  }
  this.scheduledEnd = startAt + buffer.duration;
  this.nodes.push(node);
  node.onended = () => {
    this.nodes = this.nodes.filter((n) => n !== node);
    if (this.nodes.length === 0) {
      this.onEndedCallbacks.forEach((fn) => fn());
    }
  };
  return node;
}
```
