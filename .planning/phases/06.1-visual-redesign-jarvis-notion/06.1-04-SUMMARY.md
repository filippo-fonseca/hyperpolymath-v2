## Decisions Made

All key decisions captured in frontmatter `key-decisions:` above (12 decisions across token discipline, motion patterns, register choices, and shared-infra scope). Highlights:

1. **PriorityChip uses opacity ladder, not hue** — keeps document surfaces calm vs Phase 6's per-priority pills.
2. **Motion 12 + dnd-kit single-div pattern** — motion.div IS the sortable node; transform via style, layout/exit via Motion. Canonical 2026 idiom.
3. **AnimatePresence mode="popLayout" as the parent contract** for any list view with exit animations — used in TaskList + KanbanColumn + CapturesFeed identically.
4. **Hover left-edge accent (border-l-2 transparent → hover:--edge) is the universal document-tier affordance** — repeated verbatim across TaskListRow + CaptureCard.
5. **Projects detail page is Notion-pure** — strips every Card chrome, mono only on metadata strip. Most aggressive register shift on document surfaces.
6. **DynamicIcon strokeWidth prop addition is shared-infra scope** — solves both Plan 04 (this) and Plan 05 (parallel SidebarTree) typecheck needs at once.
