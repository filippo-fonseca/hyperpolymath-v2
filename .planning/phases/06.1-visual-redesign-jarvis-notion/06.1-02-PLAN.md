<!-- The 7-state JARVIS Console machine, fully specified per UI-SPEC §6b -->

## State 1: idle
- Console input at rest
- 1px `--edge-hud` border
- No animations on input
- Status pill: "READY", `--ink-muted` text, 1px `--edge-hud` border
- Bottom rail shows last-known latency in `--ink-muted` mono 11px

## State 2: focused-idle (input focused, no text yet)
- Border thickens to 2px `--hud-cyan`
- Add `.hud-focus-breathe` class to input wrapper → `--ring-hud` breathes 8px → 14px glow → 8px on 2400ms loop via `--ease-in-out-circ`
- Status pill stays "READY"
- Linear's "physical light source moves through space" precedent

## State 3: typing (input has unsubmitted text)
- Border stays 2px `--hud-cyan`
- Every 8 keystrokes, a 4px cyan dot appears at top-right of input for 240ms via `--ease-out-quart` (Motion 12 AnimatePresence with key=keystroke-counter)
- Status pill stays "READY" (the dot is acknowledgment, not agent-typing indicator)

## State 4: submitting (ignite) — fires on Enter
- 320ms total
- Input border flashes `--hud-cyan` → `--hud-cyan-bright` → `--hud-cyan` via `.hud-submit-ignite-border` animation (320ms with `--ease-out-back` for overshoot)
- A 1px horizontal cyan scan line drops from input bottom over 320ms via `.hud-submit-scan-drop` (translateY 0 → 80px, opacity 1 → 0, `--ease-out-quart`)
- Caret transforms (200ms): cyan bar → upward arrow → fades out (via `.hud-submit-caret-arrow` or Motion 12 animate prop)
- Status pill snaps "READY" → "SENDING" then to "THINKING" once stream connection is open
- Dot pulse on pill state change (200ms scale 1 → 1.4 → 1)

## State 5: thinking (radial sweep) — fires when SSE connection is open, before first token
- Thin 1px `--hud-cyan-dim` ring drawn around leading character of submitted prompt
- Arc-tip (`--hud-cyan-bright`, 30° of circle) sweeps via `.hud-thinking-sweep` 1.4s/rotation linear loop
- Ring entrance: 200ms fade-in via `--ease-out-quart`
- Status pill: "THINKING"
- Ring fades out (200ms) when first token arrives
- Reduced motion: static quarter-fill ring (still indicates "working")

## State 6: streaming
- Thinking ring fades out (200ms)
- JARVIS prose typewriter-streams into scrollback via `textDelta`
- Render in **JetBrains Mono 500 italic 16px** — single biggest type change in the app
- 2px `--hud-cyan-bright` caret trails last rendered character with `.hud-streaming-caret` class (1.1s opacity + box-shadow pulse)
- Light-trail: 32px wide horizontal `--hud-cyan-glow-soft` gradient trails 8px behind caret, soft-falloff
- Status pill: "STREAMING"
- Light-trail is rendered as a `<div>` positioned absolutely behind the caret with `background: linear-gradient(90deg, transparent, var(--hud-cyan-glow-soft), transparent)`, `width: 32px`, `transform: translateX(-32px)` relative to caret. Width and position update via Motion 12 `layout` prop following caret position.
- Reduced motion: caret = static 2px bar, no pulse, no light-trail

## State 7: done (resolved) — first non-textDelta event arrives OR streaming completes
- Caret + light-trail fade out (160ms via Motion 12 exit)
- One-shot `.hud-scan-line` (420ms) sweeps top-to-bottom across the assistant turn region with `--hud-cyan-bright` 70%-stop gradient
- Status pill snaps back to "READY"
- Then receipts materialize (see receipt choreography below)
- Reduced motion: scan line not mounted

## State 8: error
- Status pill snaps to "ERROR" briefly (1.6s) then back to "READY"
- Assistant turn region: `.hud-error-glitch` class triggers 80ms `transform: translateX(2px)` then snap back
- Error receipt gets a 3px `--ink-coral` left edge (overrides intent dot/border treatment)
- Reduced motion: no glitch class added; coral edge appears immediately


## Receipt Materialize Choreography (UI-SPEC §6c)

| Phase | Visual |
|---|---|
| queued | 1px --edge-hud SVG rect outline traces clockwise via `.hud-receipt-outline-trace` (360ms stroke-dasharray reveal); then `.hud-receipt-shimmer` background loops 1800ms until action arrives |
| landing | Shimmer stops; content fades opacity 0→1 + y: 4px→0 over 220ms via Motion 12; intent dot pulses scale 1→1.4→1 over 280ms; corner crops flash to --hud-cyan-bright for 160ms then settle to --edge-hud |
| resolved (post-undo) | After 5s undo window: corner crops dim --edge-hud → --edge (380ms); one soft --hud-cyan-glow-soft pulse through card body (380ms) |
| undo invoked | `.hud-undo-wipe` left-to-right mask over 320ms revealing strikethrough in --ink-muted; full card fades to opacity 0.5 over 200ms; removed after 1000ms |
| error | Coral 3px left edge appears immediately; no materialize; .hud-error-glitch fires once at land |


## Status Pill State Vocabulary (UI-SPEC §12c)

| State | Copy | Visual |
|---|---|---|
| idle | READY | --ink-muted text, --edge-hud border, --hud-cyan dot |
| submitting | SENDING | --hud-cyan text, --hud-cyan border, --hud-cyan-bright dot |
| thinking | THINKING | --hud-cyan text, --hud-cyan border, --ink-amber dot |
| streaming | STREAMING | --hud-cyan text, --hud-cyan border + --hud-cyan-glow bg, --hud-cyan-bright dot |
| error | ERROR | --ink-coral text, --ink-coral border, --ink-coral dot |
| undo window | UNDO 5s (countdown ↓) | --ink-amber text, --edge-hud border, --ink-amber dot |

All pills: `px-2 py-0.5`, mono 11px uppercase tracking 0.08em, 6px leading filled dot, 240ms dot-scale pulse on state change.


## Edge Instrumentation (UI-SPEC §5a bottom rail + §6d)

Bottom of JARVIS Console — `hidden md:flex` per UI-SPEC §10c (drops below 768px).

```
╶── LATENCY 287ms · CACHE 92% · LAST 4s ago ──╴
```

- Mono 11px uppercase tracking 0.08em
- Opacity 0.4 baseline; brightens to 0.85 on hover within 80px
- Three data points: LATENCY (last turn TTFA ms), CACHE (cache hit %), LAST (time since last turn)
- Values pulse `.hud-edge-tick` class for 120ms when underlying value updates
- Data source: `jarvis_events` last-N + current SSE turn metrics (read from useQuery hook with 30s staleTime)
- For Phase 6.1: if no telemetry available, fall back to static placeholder values (`LATENCY —ms`, `CACHE —%`, `LAST —`); this prevents the rail from feeling broken on first visit


## Corner Crops (UI-SPEC §1b + §6e)

Four L-brackets at each corner of the JARVIS Console viewport (NOT page-wide):
- 12px legs (default), configurable via `size` prop
- 1px stroke `--edge-hud`
- `.hud-corner-crop` class for breathing animation (6s opacity 0.45→0.6→0.45)
- aria-hidden="true"
- Positioned absolute within the .agent-mode-scope wrapper
- Render as SVG (`<svg width="12" height="12">` containing two `<line>` elements per corner)
- Below 768px the page-level corner crops hide; only card-level corner crops remain

'use client';

import { motion } from 'motion/react';

export type HudStatusState = 'ready' | 'sending' | 'thinking' | 'streaming' | 'error' | 'undo';

interface HudStatusPillProps {
  state: HudStatusState;
  undoSecondsRemaining?: number;
  className?: string;
}

const stateConfig: Record<HudStatusState, { label: string; dot: string; text: string; border: string }> = {
  ready:     { label: 'READY',     dot: 'var(--hud-cyan)',        text: 'var(--ink-muted)', border: 'var(--edge-hud)' },
  sending:   { label: 'SENDING',   dot: 'var(--hud-cyan-bright)', text: 'var(--hud-cyan)',  border: 'var(--hud-cyan)' },
  thinking:  { label: 'THINKING',  dot: 'var(--ink-amber)',       text: 'var(--hud-cyan)',  border: 'var(--hud-cyan)' },
  streaming: { label: 'STREAMING', dot: 'var(--hud-cyan-bright)', text: 'var(--hud-cyan)',  border: 'var(--hud-cyan)' },
  error:     { label: 'ERROR',     dot: 'var(--ink-coral)',       text: 'var(--ink-coral)', border: 'var(--ink-coral)' },
  undo:      { label: 'UNDO',      dot: 'var(--ink-amber)',       text: 'var(--ink-amber)', border: 'var(--edge-hud)' },
};

export function HudStatusPill({ state, undoSecondsRemaining, className = '' }: HudStatusPillProps) {
  const cfg = stateConfig[state];
  const displayLabel = state === 'undo' && undoSecondsRemaining != null ? `${cfg.label} ${undoSecondsRemaining}s` : cfg.label;
  const bg = state === 'streaming' ? 'var(--hud-cyan-glow)' : 'transparent';
  return (
    <div
      role="status"
      aria-live="polite"
      aria-label={`JARVIS status: ${state}`}
      className={`inline-flex items-center gap-1.5 px-2 py-0.5 rounded-sm font-mono text-[11px] uppercase tracking-[0.08em] transition-colors duration-200 ease-out ${className}`}
      style={{ color: cfg.text, borderColor: cfg.border, backgroundColor: bg, border: `1px solid ${cfg.border}` }}

  const prev = useRef<T>(value);
