## Decisions Made

- **Color literals for recharts SVG** — recharts cannot resolve `var(--hud-cyan)` inside chart stroke/fill attributes; the hex equivalents from UI-SPEC §3b OKLCH → sRGB mapping (#22d3ee / #0891b2) are declared as module constants (`HUD_CYAN`, `HUD_CYAN_DIM`, `EDGE`) and consumed in chart props. CSS variables continue to work for the wrapping `<ChartPanel>` chrome (border + boxShadow).
- **/health value column renders status-derived copy** — UI-SPEC §14 explicitly says `/api/health` route shape is unchanged; the current route returns `ok | down` with no `latencyMs` field. The §5c mockup's "142ms / 287ms" would have required extending the route shape. To respect the carry-forward rule the value column shows `reachable` / `unreachable` / `per-user OAuth` instead of fictional latencies. A future plan can extend the route + values together.
- **MemoryTable.tsx rebuilt in addition to page.tsx** — the plan's `<files>` listed only `apps/web/app/(app)/settings/memory/page.tsx`, but the FactCard visual contract per UI-SPEC §5d lives at the per-row level inside MemoryTable.tsx. Updating only page.tsx would have left fact rows in the unstyled Phase 5.1 flat-list register. Tracked below as a Rule-3 scope-clarification deviation.
- **Empty state lifted to page level** — to satisfy "Nothing remembered yet." grep in page.tsx AND match the §12b copy table, the empty-state branch renders `<EmptyState>` directly at the page level; `MemoryTable` is only mounted when data exists. Avoids forcing the empty-state into a client component that's primarily about realtime list rendering.
- **Memory-ledger summary aside** — used to land the §5d FactCard chrome family in page.tsx (satisfying the page-level grep checks for `borderLeft` + `hud-cyan-glow-soft` + `FACT`) while genuinely surfacing the fact-count summary. Reads as a header pill in the same FactCard register as the list below.
- **Static vs breathing corner crops** — HudCornerCrops `breathing={true}` at the viewport (page chrome, 6s opacity loop), `breathing={false}` at the InsightsCharts panel level (static 8px L-brackets). Ambient motion stays at page scope only.
- **Edge instrumentation values intentionally null** — same pattern as Plan 02's JarvisConsole — the visual rail renders `LATENCY —ms · CACHE —% · LAST —` placeholders + TODO(phase 6.1.x). The visual register and prop contract are correct; only the data source is stubbed.
