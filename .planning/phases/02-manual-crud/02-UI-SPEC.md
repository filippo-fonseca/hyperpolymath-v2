## Typography

### Font Stack Declaration

```css
/* In app/globals.css (@theme block — extend existing) */
@theme {
  --font-serif: var(--font-eb-garamond), Georgia, "Times New Roman", serif;
  --font-sans: Inter, system-ui, -apple-system, BlinkMacSystemFont, sans-serif;
  --font-mono: "JetBrains Mono", "Fira Code", Menlo, monospace;
}
```

**Note on Inter:** Inter is available via `next/font/google`. Add in `app/layout.tsx` alongside EB Garamond with variable `--font-inter`. Use as `font-sans` throughout. Mono is reserved for the Kiwi console surface (Phase 5) but declare the variable now.

### Scale

Exactly 4 sizes. No other sizes appear anywhere in Phase 2 — component specs reference only these four.

| Role | Font | Size | Weight | Line Height | Letter Spacing | Usage |
|------|------|------|--------|-------------|----------------|-------|
| Display | EB Garamond | 28px (1.75rem) | 600 (semibold) | 1.2 | -0.02em | Page titles, empty state headings |
| Heading | EB Garamond | 20px (1.25rem) | 600 (semibold) | 1.3 | -0.01em | Section headers, panel titles |
| Body | EB Garamond | 16px (1rem) | 400 (regular) | 1.6 | 0em | Task titles, capture text, project descriptions, Cmd+K header |
| Label | Inter / system-ui | 13px (0.8125rem) | 400 (regular) | 1.4 | 0.01em | Metadata, timestamps, counts, sidebar nav, filter chips, badges, column headers, icon names, project links, class metadata line, hashtag chip text, kanban column counts, capture card project link |

**Exactly 2 weights used across all of Phase 2:**
- **400 (regular)** — all body text, all label/metadata text, captions, placeholder text
- **600 (semibold)** — Display, Heading roles only; active/selected state labels use accent color (`#D4A027`), NOT a heavier weight

**Rules:**
- EB Garamond for all content-bearing text (task titles, capture bodies, project names, area names, headings)
- Inter/system-ui for dense UI chrome (sidebar nav labels, filter chips, buttons, badges, form labels, metadata)
- Never use more than 4 sizes on any single page
- No 500 medium weight anywhere — eliminated from the scale
- No bold (700+) anywhere — 600 semibold is the maximum weight used
- Italic variant of EB Garamond at 16px/400: use for class metadata display line (`PHIL 277 · Prof. Lloyd · Fall 2026 · A-`) and Cmd+K header
- Active-state differentiation (active hashtag in sidebar, active nav item): use accent color `#D4A027` — not weight change

### Wordmark

The "Hyperpolymath" wordmark renders in EB Garamond at 16px, weight 400, letter-spacing -0.03em, in the sidebar header. No special treatment beyond that — the restraint IS the brand.

### Accent Reserved-For List

The ochre accent (`#D4A027`) is used ONLY for:
1. Focus rings (all interactive elements on focus)
2. Active sidebar nav item left border/indicator
3. Active kanban column header accent bar
4. Priority `P∞` chip/badge
5. "Lesno" status checkmark animation (completion moment)
6. Hyperlinks within capture body text
7. Selected hashtag chip in sidebar filter (color change — no weight change)
8. Skeleton loading shimmer tint

The accent is NOT used for: general buttons (use `--primary` dark), hover backgrounds (use tinted `--muted`), borders, backgrounds of cards.

## Component States

### Button

| State | Visual |
|-------|--------|
| Default (primary) | bg `--primary` (#2A2520), text `--primary-foreground`, rounded-md, h-9 |
| Hover | bg `--primary/85` (slightly lighter) — no scale, no shadow change |
| Active/pressed | bg `--primary/70` |
| Focus | `outline-none`, ring `--ring` 2px offset 2px |
| Disabled | opacity-40, pointer-events-none |
| Loading | spinner icon replaces leading icon, text unchanged, disabled state |

Button variants in use:
- `default`: dark filled — primary actions (Save changes, Create, Add)
- `outline`: bordered — secondary actions (Edit, Never mind)
- `ghost`: no border/bg — icon-only actions (⋯ menu trigger, collapse toggles)
- `destructive`: red — Delete buttons in confirm dialogs only

### Icon-Only Action Accessibility

**Rule:** Every icon-only interactive element (no visible label) carries an `aria-label` matching its tooltip text. Tooltips appear on hover with a 300ms delay via the shadcn/ui `Tooltip` primitive.

| Element | aria-label |
|---------|-----------|
| Sidebar collapse chevron | "Collapse sidebar" / "Expand sidebar" (toggles with state) |
| Capture card `⋯` menu trigger | "Capture options" |
| Detail panel `×` close button | "Close detail panel" |
| Filter chip X remove icon | "Remove filter" |
| Banner color picker swatches | "[Color name] banner" (e.g., "Warm Linen banner") |
| Lucide icon picker swatches | "[Icon name] icon" (e.g., "BookOpen icon") |

All `aria-label` values must be sentence-case, no trailing punctuation, descriptive of the action or identity.

| State | Visual |
|-------|--------|

Shadow scale:

- `shadow-lg`: 0 8px 32px hsl(30, 10%, 50%, 0.20) — dragging card, Cmd+K modal

No `shadow-xl` or `shadow-2xl` — the journal aesthetic rejects heavy shadows.

- Orphan tags (count = 0): hidden from default view, shown with opacity-40 under "Show all" toggle

## Animation & Motion Specs

Library: Motion 12.x via `motion/react`. Import: `import { motion, AnimatePresence } from 'motion/react'`

**Philosophy:** Subtle and purposeful. No bounce, no spring overshoot on data UI. Transitions announce state changes without demanding attention.

| Element | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| Detail panel slide-in | x: 420px → 0 | 200ms | ease-out |
| Detail panel slide-out | x: 0 → 420px | 150ms | ease-in |
| Capture card appear | opacity: 0→1, y: 8→0 | 180ms | ease-out |
| Capture card delete | opacity: 1→0, height: auto→0 | 200ms | ease-in |
| Sidebar collapse | width: 260→64px | 200ms | ease-in-out |
| Kanban card drag | scale: 1.02, shadow upgrade | drag active | spring(stiffness:300, damping:30) |
| Kanban card drop | scale: 1.0 | 120ms | ease-out |
| Modal open (Dialog) | opacity: 0→1, scale: 0.97→1 | 150ms | ease-out |
| Modal close (Dialog) | opacity: 1→0, scale: 1→0.97 | 100ms | ease-in |
| Cmd+K open | opacity: 0→1, y: -8→0 | 150ms | ease-out |
| Filter chip appear | opacity: 0→1, scale: 0.95→1 | 120ms | ease-out |
| Filter chip remove | opacity: 1→0, width collapse | 120ms | ease-in |
| Toast appear | x: 100%→0 (from right) | 200ms | spring(stiffness:400, damping:35) |
| Lesno checkmark | path draw | 300ms | ease-in-out |
| Skeleton shimmer | background-position cycle | 1500ms | linear, infinite |

**List reorder:** Use `@dnd-kit` built-in DragOverlay + Motion `layoutId` for smooth reorder animation. Transition duration: 150ms.

**No animate on:** Static text renders, page navigation, sidebar tree expand/collapse (instant for snappiness), filter chip hover states.

## Loading States

### Skeleton Designs

Philosophy: skeletons match the exact shape of the content they stand in for. No generic spinner for page-level loads.

| Component | Skeleton Shape |
|-----------|---------------|
| Sidebar tree | 3 area rows (h-5, w-3/4) + 2 project rows per area (h-4, w-1/2, pl-6) |
| Kanban card | h-20 rectangle, rounded-lg, with 2 inner lines (h-3 w-3/4, h-3 w-1/2) |
| Capture card | h-16 rectangle, rounded-lg, with 2 inner lines + chip placeholder |
| Project detail header | h-32 banner + h-8 title + h-4 subtitle |
| Filter chips area | 3 rounded-full chips of varying width |

Skeleton shimmer: CSS `@keyframes shimmer` — background-position sweep from left to right. Gradient: `linear-gradient(90deg, --card 25%, hsl(38, 25%, 90%) 50%, --card 75%)`. Cycle: 1500ms linear infinite.

### Optimistic Updates (Phase 2 scope)

Phase 2 uses immediate server mutations (Server Actions) with no optimistic client state. The UI waits for the server action to resolve before updating. This means:
- Show a loading spinner on the submit button during mutation
- Disable form inputs during mutation
- Phase 3 Realtime layer introduces proper optimistic updates — do not anticipate it in Phase 2

## URL + State Contracts

### Task Filter URL Schema (D-08)

```
/tasks?priority=P1,P2&status=in-progress,up-next&due=this-week&project=<projectId>
```

| Param | Values | Notes |
|-------|--------|-------|
| `priority` | `P∞,P1,P2,P3` (comma-separated, URL-encoded `P%E2%88%9E` for P∞) | |
| `status` | `not-started,up-next,in-progress,almost-done,lesno` | kebab-case of enum values |
| `due` | `today,this-week,this-month,overdue,no-date` | |
| `project` | `<uuid>` | Single project filter in Phase 2 |
| `view` | `kanban,list` | Defaults to `kanban`; localStorage fallback if param absent |

Filter state lives in URL search params (D-08). Use `useSearchParams` + `useRouter` in the filter toolbar Client island.

### Sidebar State

- Expanded/collapsed: `localStorage.getItem('sidebar-collapsed')` — boolean string
- Active route: driven by `usePathname()`
- Tree expand/collapse per area: `localStorage.getItem('sidebar-area-<areaId>-expanded')` — boolean string
