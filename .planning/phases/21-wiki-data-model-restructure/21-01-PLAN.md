<objective>
Restructure the wiki data model at the database + Drizzle-schema layer: decouple folders from projects, give folders arbitrary-depth hierarchy via a self-FK, and replace the required project link with an M:N junction.

This plan writes migration `0034_wiki_data_model_restructure.sql` (hand-written, idempotent, data-preserving), updates the Drizzle schema to match so generated TS types are correct, registers the new table for Realtime, and APPLIES the migration to the live local database.

Purpose: Establishes the schema that every later wiki phase (23 tree UI, 24 linking UX) builds on. Without folders being project-independent and nestable, the new Wiki organization cannot exist.

Output: Applied migration 0034, updated `schema.ts`, `folder_projects` registered as a Realtime table. WIKI-MODEL-01 (parent_id self-FK), WIKI-MODEL-02 (project_id removed, links preserved), WIKI-MODEL-03 (folder_projects junction + RLS) all satisfied at the data layer.
</objective>
