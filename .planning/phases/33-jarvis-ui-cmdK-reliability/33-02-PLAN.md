<objective>
Rearchitect JarvisScrollback.tsx from a flat terminal log to an iMessage-style bubble layout (per JAR-UI-01, JAR-UI-02, JAR-UI-03). Fix the hud-focus-breathe bug in JarvisInput. Upgrade the composer strip to glass.

This plan is the visual core of Phase 33. The JARVIS tab will transform from a mono terminal log into a premium AI chat interface matching the "Apple Messages × JARVIS HUD × Sunday Robotics" brief.

Layout spec (per locked decisions D-01 through D-05 in CONTEXT.md):
- User turns: right-aligned bubble, neutral glass surface (--glass-bg background + --glass-raise + --glass-drop shadows), no cyan, rounded-2xl, max-width 72%, font-sans text-[15px], right-to-left text flow
- JARVIS turns: left-aligned column; a small "JARVIS" label in --hud-cyan font-mono text-[11px] uppercase above the bubble; the bubble uses the .glass-tile class PLUS an additional box-shadow: 0 0 20px var(--hud-cyan-glow-soft) to add the cyan ambient halo; content inside remains font-mono italic font-medium text-base for prose
- Bubble entry animation: Motion 12 motion.div, initial={{ opacity: 0, y: 6 }}, animate={{ opacity: 1, y: 0 }}, transition={{ duration: 0.22, ease: [0.25, 1, 0.5, 1] }} — matches existing JarvisReceipt animation curve; skip when shouldReduce
- The HudThinkingRing + THINKING label, streaming caret, ScanRevealOverlay, JarvisClarification, and JarvisReceipt cards all move INSIDE the JARVIS bubble div so they are contained within the glass surface
- Error state: the assistant bubble itself gets border-left: 3px solid var(--ink-coral) + hud-error-glitch class (same as before but now scoped to the bubble border)
- Retry button: inside the error bubble below errorMessage text — a small font-mono text-[12px] button that calls onRetry(turn.id) passed from JarvisConsole; if onRetry prop is not provided (to avoid breaking the side-panel), the button is simply not rendered
- The > prompt character and flat row layout are removed entirely
- Date dividers, "Older messages" button, and empty state hint are unchanged in content, only their container padding adjusts to suit the bubble column

Composer strip (JarvisConsole.tsx line 1227): replace `border-t bg-card px-6 py-3` with `relative z-10 border-t px-6 py-3` plus inline styles: backgroundColor: "var(--glass-bg)", backdropFilter: "blur(12px)", borderTopColor: "color-mix(in oklch, var(--edge-hud) 60%, transparent)".

JarvisInput.tsx focusedIdle bug (line 436-442): add "hud-focus-breathe" to the className array when focusedIdle is true and !shouldReduce. The existing className array already handles hud-submit-ignite-border; add a parallel condition for hud-focus-breathe.

Purpose: After this plan, the JARVIS tab matches the locked visual brief. Wave 3 (Plan 03) handles receipt polish, streaming indicator placement, dead-code removal, and the final full-path checkpoint.

Output: Three modified files. Commit per logical unit: scrollback rearchitecture first, then composer + input fixes.
