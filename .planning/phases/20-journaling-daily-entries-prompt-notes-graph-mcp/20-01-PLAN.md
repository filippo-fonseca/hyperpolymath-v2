|----------|-------------|
| client → Postgres (RLS) | A signed-in browser issues reads/writes against `journal_entries`. RLS (`user_id = auth.uid()`) is the enforcement boundary; the table holds personal journal text. |
| Realtime broadcast | Postgres change events for `journal_entries` fan out over the `supabase_realtime` publication; the channel filter (`user_id=eq.<id>`) plus RLS-aware Realtime auth scope them to the owner. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-20-02 | Tampering | second insert for an existing (user, date) | mitigate | `UNIQUE(user_id, date)` constraint makes a duplicate-day insert conflict at the DB level; plan 20-02's upsert uses it as the ON CONFLICT target. |
