  <action>
Add a copy-to-clipboard control to `apps/web/components/captures/CaptureCard.tsx`. Reuse the established patterns already in this file — do not introduce a new styling system or a clipboard utility (none exists in the repo; use the platform API directly).

**Icon + state:**
- Import `Copy` (and optionally `Check`) from `lucide-react` alongside the existing `MoreHorizontal` import (line 3).
- Add a local `const [copied, setCopied] = useState(false);` near the other useState hooks (~lines 119-122).

**Copy handler:**
- Add a `handleCopy` function. It must `e.stopPropagation()` (and `e.preventDefault()`) so the card's `onOpen` click does NOT fire. Then call `navigator.clipboard.writeText(capture.content)`.
- On success: `setCopied(true)`, fire `toast("Copied to clipboard.")` (sonner is already imported), and reset `copied` to false after ~1.2s via setTimeout.
- Graceful fallback (CONTEXT: copy must degrade gracefully): wrap in a guard — if `navigator.clipboard?.writeText` is unavailable, either attempt a `document.execCommand("copy")` fallback OR fire `toast.error("Couldn't copy.")`. Never let an unhandled rejection escape; `.catch(() => toast.error("Couldn't copy."))` on the writeText promise.

**Placement + responsive behavior (touch-friendly mobile + hover-reveal web):**
- Add the copy button into (or directly beside) the existing top-right action region (lines 199-233). It must sit inside a container that `stopPropagation`s on click, matching the ⋯ menu wrapper.
- **Web (pointer-fine):** hover-reveal — apply the same `opacity-0 transition-opacity group-hover:opacity-100` treatment the ⋯ menu uses so the copy button appears on card hover, consistent with the existing affordance.
- **Mobile (touch):** the button must be reachable without hover. Use a responsive utility so it is always visible / adequately tappable on touch (e.g. base `opacity-100` overridden to the hover-reveal only at a pointer-fine / sm+ breakpoint, or `@media (hover: none)` via the project's `pointer-fine` convention if present in globals). Ensure a comfortable tap target (the existing Button `h-6 w-6` is small for touch — use at least the same as the ⋯ trigger, and prefer a slightly larger hit area on touch). Keep it visually quiet so it doesn't fight the card content.
- Use the same `Button variant="ghost" size="sm"` + `aria-label="Copy capture"` shape as the ⋯ trigger (lines 210-218). When `copied` is true, swap the icon to `Check` (and/or change the aria-label to "Copied") for inline feedback in addition to the toast.

**Do not** change delete/convert/open behavior, the motion wrapper, or `CaptureBody`. This is purely additive. The control must work in both `compact` and non-compact modes (it lives in the absolute-positioned action region, which renders in both).

Implements CAP-COPY-01.
