# Quick 260712-j32: Harden link-preview fetch (SSRF + unbounded body) Summary

Closed GitHub issue #261 by hardening `apps/web/lib/link-preview/fetch.ts` against SSRF (redirect-into-internal-target, cloud-metadata/loopback/RFC1918 access) and a memory-exhaustion DoS (unbounded `arrayBuffer()` buffering), while preserving the module's "never throws — always returns a LinkPreviewResult" contract and all existing behavior.

## What was built

- **`ssrf.ts` (new)** — Node built-ins only (`node:net`, `node:dns/promises`), no npm deps.
  - `isPrivateAddress(ip)`: classifies IPv4 (loopback, RFC1918, 169.254/16 link-local incl. the 169.254.169.254 metadata endpoint, CGNAT 100.64/10, TEST-NET-1, multicast/reserved ≥224) and IPv6 (`::1`, `::`, fe80::/10 link-local, fc00::/7 unique-local). IPv4-mapped IPv6 (`::ffff:a.b.c.d`) is unwrapped and delegated to the v4 branch so a mapped literal can't smuggle a blocked v4 address past the v6 checks. Fails closed (returns `true`) on any non-IP input.
  - `assertHostAllowed(url)`: strips IPv6 brackets, blocks IP-literal hosts in a private range, and for hostnames rejects when `lookup(host,{all:true})` returns zero records or any resolved address is private (DNS-rebinding guard).
- **`fetch.ts` — `fetchWithTimeout`**: `redirect:"follow"` → `redirect:"manual"` with a bounded loop of at most 5 hops. Every hop (initial URL + each `Location`) is parsed, protocol-gated to http(s), and passed through `assertHostAllowed`. One `AbortController` is reused across hops so the 6s total budget is preserved; user-agent/accept headers unchanged. Errors propagate to the existing `fetchLinkPreview` try/catch → `errorResult` (no swallowing).
- **`fetch.ts` — `fetchGeneric`**: `res.arrayBuffer()` + slice replaced with `readCappedText(res)`, a `getReader()` loop that accumulates chunks up to `MAX_HTML_BYTES`, pushes only the remaining-budget slice on the final chunk, then `reader.cancel()`s the download. Bodyless responses fall back to `res.text()` sliced to the cap. Decode semantics and all downstream parsing / og:image resolution unchanged.
- **`link-preview-ssrf.test.ts` (new)**: pure unit tests (no network) exercising `isPrivateAddress` across all blocked/allowed representatives from the plan plus the fail-closed non-IP case.

## Threat mitigations (from plan threat register)

- **T-j32-01 (SSRF to internal/metadata)** — mitigated: per-hop `assertHostAllowed` + IP-range classifier block loopback/RFC1918/link-local (169.254.169.254)/unique-local/reserved.
- **T-j32-02 (redirect bypass)** — mitigated: `redirect:"manual"` + per-hop validation + http(s)-only targets + 5-hop cap.
- **T-j32-03 (unbounded body DoS)** — mitigated: streamed `getReader()` loop cancels at `MAX_HTML_BYTES`; body never fully buffered.
- **T-j32-04 (DNS rebinding)** — mitigated: reject when any resolved address is private; residual TOCTOU window accepted (fail-soft single-user fetcher).
- **T-j32-SC (supply chain)** — no new dependencies; Node built-ins only.
