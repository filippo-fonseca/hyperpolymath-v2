# Quick 260615-m68: Local Kiwi auto-dev worker with launchd Summary

A local, unattended macOS worker under `tools/kiwi-autodev/` that picks up open `kiwi-drafted` GitHub issues once per day while the laptop is open, resolves each in an isolated git worktree/branch via headless Claude (`/gsd:quick`), never pushes, leaves recaps, and reports a best-effort run summary to the prod `/api/dev-runs` endpoint.

## What was built

- **config.sh**: sourced shell config exporting the documented defaults (`MAX_ISSUES=3`, `PER_ISSUE_TIMEOUT_MS=2700000`, `MODEL=opus`, `LABEL=kiwi-drafted`, `EARLIEST_UTC_HHMM=0610`, `BRANCH_PREFIX=kiwi/auto`, `REPO_SLUG`, `REPORT_URL=https://hyperpolymath.com`) plus a prominent never-commit-secret note.
- **gate.sh**: fast eligibility gate (no daily lock, time-of-day >= window, at least one open `kiwi-drafted` issue). Exits non-zero quietly on the ineligible path; all diagnostics go to stderr.
- **launchd-entry.sh**: sources config, runs the gate, and only on success execs `node run.mjs`. A failing gate is the normal idle path (exit 0).
- **run.mjs**: zero-dependency Node ESM orchestrator. Lists issues oldest-first capped at `MAX_ISSUES`, creates a worktree/branch per issue off `origin/main`, spawns headless Claude detached, enforces the per-issue timeout via a Node `setTimeout` that kills the whole process group (`process.kill(-pid, ...)`), classifies `done|skipped|failed|timed-out` with per-issue isolation, computes `commitCount` via `git rev-list --count origin/main..<branch>`, aggregates `recap-<date>.md` with a merge-hint review list, removes worktrees while keeping branches, POSTs a best-effort summary to `/api/dev-runs` with a Bearer secret from env or `apps/web/.env.local`, fires an `osascript` notification, and writes the date-stamped lock LAST.
- **githooks/pre-push**: POSIX-sh hard guard that blocks pushes when `KIWI_AUTOMATION` is set or any pushed ref is under `refs/heads/kiwi/auto/*`; normal pushes pass.
- **install-hook.sh**: resolves the hooks dir from `core.hooksPath`, installs a dispatcher (or chains a sentinel-guarded sidecar into an existing pre-push) without overwriting, never touches `pre-commit`, idempotent.
- **com.hyperpolymath.kiwi-autodev.plist**: LaunchAgent template with `__REPO__` placeholder, `StartInterval 1800`, `RunAtLoad`, PATH including `/opt/homebrew/opt/node@20/bin` and `/opt/homebrew/bin`, log paths under `tools/kiwi-autodev/logs`, explicit no-secret comment.
- **install.sh / uninstall.sh**: idempotent installer/uninstaller (substitute `__REPO__`, bootout-then-bootstrap with `load -w` fallback, run `install-hook.sh`, print next steps / reverse cleanly).
- **README.md**: documents what it does, the honest safety model and residual risk, reporting + secret source, and install/review/tune/uninstall.
- **.gitignore**: appended `.kiwi-auto/` and `tools/kiwi-autodev/logs/`.
