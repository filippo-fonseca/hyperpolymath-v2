  <action>
Create `tools/strava-mint.mjs` — an interactive Node script the user runs ONCE to bootstrap the Strava refresh_token into Supabase. Idempotent (re-running overwrites the row).

Behavior:
1. Read `STRAVA_CLIENT_ID` and `STRAVA_CLIENT_SECRET` from `apps/web/.env.local` (load via dotenv — `import 'dotenv/config'` after `process.chdir('apps/web')` or pass an explicit path). If missing, print clear instructions: register an app at https://www.strava.com/settings/api, copy client_id + client_secret into `.env.local`.
2. Build the authorize URL:
   ```
   https://www.strava.com/oauth/authorize
     ?client_id=<id>
     &redirect_uri=http://localhost:53682/callback
     &response_type=code
     &approval_prompt=auto
     &scope=activity:read_all
   ```
3. Spin up a one-shot Node `http.createServer` on port 53682 listening for `/callback?code=<>`.
4. `open` the authorize URL in the default browser (use `child_process.exec('open <url>')` on darwin — this is a darwin-only tool per CLAUDE.md project context).
5. When the callback hits, exchange the code:
   ```
   POST https://www.strava.com/api/v3/oauth/token
     client_id, client_secret, code, grant_type=authorization_code
   ```
6. Persist to Supabase `integration_tokens` (provider='strava'). Use the postgres driver directly with the project's `DATABASE_URL` (or `POSTGRES_URL`) env var. Upsert on `(user_id, provider)`.
7. For `user_id`: prompt the user for it interactively (`readline`), OR read from a `USER_ID` env var if set.
8. Print "Done — refresh_token persisted. Strava panel should now load on next /insights visit." and exit.

Error cases:
- Missing env vars → friendly instructions, exit 1.
- Token exchange returns 4xx → print Strava's error body, exit 2.
- DB write fails → print SQL error, exit 3.

This is a tool script, not app code. Plain `.mjs`, no TypeScript, minimal deps (`postgres` + Node built-ins). Make executable: `chmod +x tools/strava-mint.mjs` and add shebang `#!/usr/bin/env node`.
